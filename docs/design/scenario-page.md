# The Scenario page

Part of the [design](../design.md). Terms in **bold** are defined in [CONTEXT.md](../../CONTEXT.md).

A Session starts on the **Scenario page**: a Scenario picked on Home, or a typed Brief, opens it, and **Expand** runs as it opens ([ADR 0032](../adr/0032-scenarios-are-stories-kept-in-each-session.md)). Expand is one Text Model call, sparse on purpose: from a Brief it sorts what's stated into the Scenario's parts, names the People (the Brief's "I" is the player's person), writes the Opening and says who plays whom; from a Scenario (sent as it stands on the page, so a Retry keeps the edits made since) it only says who plays whom if the Scenario doesn't, and names the People if it lists none. What a Scenario states is kept by the code whatever the model replies. Every other blank stays blank, up to ten of them showing Expand's suggestion in grey. Every part has a *Suggest* button that writes a suggestion into it, as Roleplay's Suggest writes a Message: Expand's, if the part has one and is empty; otherwise a short call for that part alone, sent the Scenario as it stands without that part, and what's typed there as notes to build on (none when it's the last suggestion untouched, so pressing again writes a new one). Until the Session starts, the Scenario as edited is kept per browser, and the header leads back to it as it does to the current Session; opening a different one on Home asks first, as it takes its place. Each part can be edited by hand, People added or removed, and who the player and the Text Model play picked (or left to the Cast). Start sends the Scenario as it's been left, which the Session keeps; starting never changes its file. The page can also save it to the player's `scenarios/` (*Save*, over its file; *Save as new*, under a new id from its title), and Home can import a Scenario file or delete one; a saved file is read back as a Scenario first, so one that wouldn't load isn't saved. If Expand fails on a Brief, Start goes on from the Brief alone.

The Scenario file format is in [scenarios.md](../scenarios.md).
